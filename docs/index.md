# kefoCloud documentation

The operator-facing documentation for this stack. Start with the **Guide** —
it is the one place project-specific facts live (layout, deployment commands,
protected resources, per-service facts, gotchas).

- **Guide** — how to deploy and operate this machine.
- **Agent rules** — how an agent must behave in this repo.
- **Issues** — open problems and resolved history.
- **Debug runbook** — how to triage an incident, read-only first.
- **Migration** — moving the stack to a new machine.
- **Skeleton** — the tokens and values every deployable file is rendered from.
- **Sandbox modules** — trying an app without touching the repo.
