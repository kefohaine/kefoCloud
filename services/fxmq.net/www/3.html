fxmq.net · index 03 — the whole stack in one look

YOUR DATA.
ONE BOX.

Cloud, mail, passwords, monitoring and Minecraft — on one Debian VPS behind a single repo. Every service is a ready-made module; the installer asks which ones you want, then builds them.

bash install.sh — the only command you need
□cloud □mail □games □vault □monitor ■edge · always

Each box above is a module you tick or skip during install — no other setup. Say the domain, hand over a Cloudflare token and a Tailscale key, and the script does the rest: hardening, DNS records, certificates, admin accounts.

after the install — two helpers

optimize

scripts/optimize.sh

Universal VPS performance optimizer: kernel/memory/network tuning, swap, THP, noatime, fstrim and cleanup. Idempotent, safe to re-run.

storage

scripts/storage.sh

Point a cheap second VPS at the box as live Nextcloud storage over the tailnet — the database stays on the main host.
