Caps are ceilings, not allocations — idle memory stays low; a runaway process hits its own wall long before the host feels it. The game server? It only runs when you start it, and the heap grows on demand.

Zero-trust posture, boring to maintain. SSH is tailnet-only. Every vhost is its own LE cert. Panel registration is closed at the edge. Backups leave the box nightly, over the tailnet, to a second VPS.

None of that is paid-tier magic — it's the default output of the installer plus a Makefile that makes the safe action the easy one.
