the repo is the server

Everything on this page is running from one repository.

No staging environment, no demo data, no screenshot. Every door below is served live by the deployment that kefohaine/server builds and operates. If you can open it, the repo already did it.

1.

One command builds all of it. A fresh VPS, three prompts (domain, Cloudflare token, Tailscale key), and the installer hardens the host, issues the certificates, writes the DNS records and brings the stack up unattended.

2.

It survives real life. Per-container RAM ceilings, healthchecks, a smoke test that blocks any push with a broken edge, and a boot-order fix for an NFS race that once took Nextcloud down — the incidents are in the git history, and so are the fixes.

3.

It's yours in an afternoon. Every value is derived from your domain at install time; the modules you don't want are one prompt away from off.

git clone https://github.com/kefohaine/server && cd server
bash install.sh # under your own domain, from the same code

Or read the source first — every file this server runs is public: github.com/kefohaine/server
