> why it's trustworthy

Nothing here is a mockup. The links below are the running deployment. The docs describe the running deployment. Break something and the smoke test blocks the push — the repo cannot drift from reality.

> why it's cheap to run

One VPS, idle under 2 GB. Every container has a hard RAM ceiling; the Nextcloud datadirectory lives on a second box over tailnet NFS, and the DB backs up to it nightly.

> why it's yours

No hardcoded domain, no hardcoded hostnames. Your domain goes in at install time and every path, cert and DNS record follows it. Modules you don't want: one prompt, off.

git clone https://github.com/kefohaine/server && cd server && bash install.sh
