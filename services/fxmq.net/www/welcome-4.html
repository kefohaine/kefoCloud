kefohaine/server — a live demonstration issue 01 — swiss edition

your server, from a repository.

This page, the cloud behind it, the mail platform, the vault — every door on this domain is served by the exact code in one public repo. Clone it to a fresh VPS and the same stack builds itself under your domain.

01

Three answers, then unattended.

The installer asks for your domain, a Cloudflare API token and a Tailscale key — then runs alone: host hardening, DNS records, per-hostname Let's Encrypt certs, and the whole module board. Admin passwords print once and are stored nowhere.

02

Every container has a ceiling.

Per-module RAM caps, healthchecks, and a smoke test that probes every live vhost — a push that would break the edge simply does not go through. Idle sits comfortably under 2 GB on the whole stack.

03

The doors you know, none you don't.

Nextcloud, Vaultwarden, Uptime Kuma, full mail with webmail, a game panel with browser Minecraft, a tailnet-only terminal. Unwanted modules are one prompt away from off.

04

It writes its own receipts.

Nightly database dumps leave the box over an encrypted tailnet to a second VPS; the Nextcloud datadirectory lives there too. When something odd happened, the git history — and the docs that grow from it — already explain it. There's even an uninstall.sh that reverses the whole thing cleanly.
