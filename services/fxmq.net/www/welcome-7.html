§2 — tolerances

idle RAM
whole stack comfortably < 2 GB — every container hard-capped
spike policy
ceilings, not allocations — a runaway hits its own wall
deploy drift
zero — smoke test probes live vhosts; broken push is refused
boot behavior
panel container up, game servers never autostart
off-site
nightly DB dumps over encrypted tailnet to a second VPS
exit route
uninstall.sh — reverses the install, module by module

§3 — employment

Procedure 01 · establish your own board

  1. git clone https://github.com/kefohaine/server
  2. cd server && bash install.sh
  3. answer three prompts (domain · CF token · tailnet key)
  4. wait ~one unattended run
  5. note the admin passwords printed once

Opt-out any module at prompt time. Unwanted doors simply never open.
